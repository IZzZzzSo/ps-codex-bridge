# PS ↔ Codex 图像桥

Photoshop UXP 插件 + 本机桥接服务，让画布截图与 Codex 桌面聊天之间的图片传输更方便。

**开发预览版 0.1.0。** 已在 macOS + Photoshop 27.0.0 验证面板加载、配对连接和滚动；截图、选区、原位像素写入等宿主 API 已单独实测。用户已在 macOS + Photoshop 27.0.0 环境反馈完整改图、原位回传和指定已有对话发送流程通过；其他环境欢迎反馈兼容性问题。

## 功能

- 截取局部选区或整个画布，记录文档、坐标和尺寸。
- 保存 PNG 与需求，支持新对话预填，以及指定已有对话打开后粘贴发送。
- 紧凑三步面板：折叠连接与目标设置、固定发送按钮和状态栏，突出显示回传操作。
- 登记本地修改结果，在 PS 中新建图层并回到原截取位置。
- 支持透明边缘与选区羽化；提供文档绑定、尺寸检查、回滚和重复回传保护。
- 面板内也可手动选择 PNG/JPEG 结果文件，不必依赖 Codex 自动登记。

## 安装

需要 macOS、Photoshop 27 或更新版本、Node.js 20+ 和 Codex 桌面应用。图像编辑工具的可用性取决于你的 Codex 账户与客户端。本项目不提供模型服务，也不附带 API 凭据。

1. 克隆或下载仓库，双击 **启动图像桥.command**（也可运行 `npm start`），保持窗口打开。
2. 用 Adobe UXP Developer Tool 添加 `plugin/manifest.json` 并加载到 Photoshop。按 Adobe 提示启用开发模式，必要时重启 Photoshop。
3. 在 PS 的 **增效工具 → PS ↔ Codex 图像桥** 打开面板，复制服务窗口显示的配对码，点击“保存并连接”。

也可双击 **启用Adobe开发模式.command** 使用项目内 Adobe 官方 CLI 辅助安装。它会下载开发依赖、显示 Adobe 条款并请求系统管理员确认，再尝试加载插件。CLI 属于较旧的工具，在新版本 Photoshop 上可能存在兼容问题，图形开发工具是另一个加载入口。

`downloads/` 中提供官方工具生成的预览 CCX 包；安装仍需 Adobe 的插件安装器或 Creative Cloud 支持。本机服务须单独启动。

## 使用

1. 在普通 RGB 文档中建立选区，或选择整个画布，点击截取。
2. 输入需求，通过“更改”设置发送目标，点击“传给 Codex”。新对话确认后发送；已有对话按 ⌘V 粘贴并发送。
3. Codex 应读取任务目录中的 `request.md` 和 `input.png`，用可用的图像工具修改并保存为本地文件。
4. 按任务文件的命令登记结果。结果就绪后，在 PS 面板点击“回传 PS”。支持原生后续操作的 Codex 客户端也可以显示回传操作按钮。

Codex 不能编辑图像或不能提供本地结果时，请使用面板中的“选择结果文件”。打开聊天的链接不会自动附加图片，任务文件会指导 Codex 读取本机截图。

## 限制与数据

- 目前面向普通 8/16 位 RGB 画布。传输和返回为 8 位 sRGB；暂不支持画板、CMYK 和 HDR/32 位文档。
- 单次最多 1600 万像素，结果文件最多 32 MiB。结果会缩放到原矩形，宽高比改变可能造成拉伸。
- 原文档关闭、插件重载、文档改名或画布几何变化后可能需要重新截取。等待期间尽量不改变原画布几何。
- 本机服务仅监听 `127.0.0.1:17321`，面板通过固定端口 `localhost:17321` 连接，使用配对码鉴权。
- 素材、需求和配对配置保存在自动生成的 `runtime/`。**不要上传或分享这个目录。** 将素材发送到 Codex 后，由相关服务按其数据政策处理。
- 回传为新像素图层，不保留可编辑文字、矢量结构，也不自动消除 AI 改图接缝。

## 开发

无需安装 npm 依赖即可运行服务与测试。

```sh
npm start
npm test
npm run check
npm run package
# 如需 Adobe CLI 和 CCX 打包：
npm run setup:adobe
npm run package:ccx
npm run dev
```

测试依赖 macOS 自带的 `sips`，需要允许临时本机 HTTP 服务。详见 [TESTING.md](TESTING.md)。

## 指定发送目标

面板新增“发送目标”。新对话可填写本机项目工作目录，目录必须真实存在；工作目录提供文件上下文，不保证自动加入侧边栏项目。已有对话模式接受 `codex://threads/<对话ID>` 或完整 ID，在目标 Codex 对话中按 ⌘⌥L 可复制本地对话链接。

已有对话模式会把任务需求复制到系统剪贴板并打开目标对话，需要用户按 ⌘V 粘贴并发送；不会自动发送，也不会新建对话。剪贴板会被本次任务需求覆盖。目标设置会在成功保存任务后记住。读取保存在桥接目录中的截图可能需要 Codex 的目录访问确认。

请使用完整对话链接，带 `...` 或 `…` 的缩略地址无法定位对话。
